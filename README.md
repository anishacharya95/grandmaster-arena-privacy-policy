# Grandmaster Arena Privacy Policy

This repository contains the public HTML privacy notice for the Android game Grandmaster Arena.

- App package: `com.aistudio.chessarena.gmarena`
- Main page: `index.html`

## Before publishing

1. Replace every `[ADD A CONTACT EMAIL ADDRESS BEFORE PUBLICATION]` placeholder in `index.html` with a monitored privacy contact email.
2. Re-check the policy against the exact release APK/AAB and all enabled Firebase or other SDK features.
3. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the deployment source.
4. After the Pages workflow completes, check the public webpage from a signed-out browser before adding it to Google Play Console.

The page is a draft until the contact placeholder is replaced and the disclosures are verified against the shipped app.
